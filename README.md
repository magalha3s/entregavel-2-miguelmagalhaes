# Entregável 2 - Harpia UFRJ

> Miguel Rangel de Magalhães

Programa para realizar anotações em imagens utilizando a biblioteca `OpenCv`.



Para **instalar** o programa nas distros `Arch` ou `Fedora` siga o procedimento abaixo:

```bash
git clone https://github.com/magalha3s/entregavel2-miguelmagalhaes.git 
python -m venv .venv 
source .venv/bin/activate
pip install opencv-python
python src/main.py
```
